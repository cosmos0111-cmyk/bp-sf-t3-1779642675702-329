마포 정보 블로그 - 네트워크 보안

글 목록

구글 상위노출 대행을 알아보다 보면 생소한 네트워크 보안 용어를 함께 마주치게 된다. 계약 전에 최소한의 용어를 알아두면 상담 과정에서 무엇을 물어야 할지 스스로 판단할 수 있고, 대행사가 설명하는 작업 범위도 더 정확하게 이해할 수 있다.

혼동하기 쉬운 개념 정리

방화벽
정해진 규칙에 따라 들어오고 나가는 트래픽을 걸러내는 장치 또는 소프트웨어.
SSL 인증서
브라우저와 서버 사이의 통신이 암호화되어 있음을 보여주는 인증 수단.
DNS
도메인 이름을 서버의 실제 주소로 변환해주는 체계.
CDN
콘텐츠를 여러 지역 서버에 분산 저장해 응답 속도를 높이는 방식.
VPN
공개 네트워크 위에 암호화된 전용 통신 경로를 만드는 기술.
취약점
시스템에서 공격에 악용될 수 있는 설계나 설정상의 약점.

상위노출 대행 상담 전 점검 순서

  1. 현재 도메인의 SSL 적용 상태 확인
  2. 서버 접근 권한 목록 정리
  3. 기존 백업 유무 확인
  4. 계약 시 작업 범위와 보안 책임 구분을 명시하도록 요청
  5. 담당자 변경 시 인수인계 절차 확인
  6. 작업 종료 후 임시 계정 삭제 여부 확인

오해하기 쉬운 부분

순위가 오르면 보안도 자동으로 좋아진다고 생각하기 쉽지만, 두 영역은 별개로 관리해야 하는 항목이다. 상위노출 작업이 진행되는 동안에도 접근 권한 관리나 로그 점검 같은 기본적인 보안 절차는 그대로 유지되어야 한다. 반대로 보안 점검을 마쳤다고 해서 검색 노출 순위가 곧바로 오르는 것도 아니므로, 두 작업의 목적을 구분해서 이해하는 편이 혼선을 줄인다.

자주 하는 실수

  • 관리자 비밀번호를 계약 종료 후에도 바꾸지 않음
  • 여러 사이트에 같은 로그인 정보를 재사용
  • 보안 패치 적용 여부를 확인하지 않고 넘어감
  • 접근 권한을 부여만 하고 회수 시점을 정하지 않음

용어별 확인 방법

용어확인 방법
SSL 인증서주소창의 자물쇠 표시와 인증서 발급 기관 확인
DNS 설정도메인 등록기관의 관리 콘솔에서 레코드 조회
서버 접근 권한계정 목록과 최근 로그인 이력 확인
보안 패치서버 소프트웨어 버전과 업데이트 이력 확인
